Privacy Statement

Last updated: February 26, 2026

Overview

MatData is committed to protecting your privacy. This privacy statement explains what data is collected, processed, or stored when you visit this website.

Data Collection by MatData

This is a static informational website. MatData does not directly collect, store, or process personal user data beyond what is collected by Google Analytics (see below). Specifically:

  • No user accounts: This website does not require registration or user accounts.
  • No cookies (except Google Analytics): MatData does not set any cookies for tracking purposes except those used by Google Analytics.
  • No data storage: This website does not store any user data in browser storage or on backend servers.

Third-Party Services

Certain third-party services involved in delivering this website may collect data independently:

Google Analytics

This website uses Google Analytics to understand how visitors interact with the site. Google Analytics collects information such as your IP address, browser type, device information, pages visited, and time spent on pages. This data is processed by Google according to their privacy policy.

You can opt out of Google Analytics by installing the Google Analytics Opt-out Browser Add-on. For more information, see Google's Privacy Policy.

GitHub Pages Hosting

This website is hosted on GitHub Pages. GitHub does not collect or store HTTP access logs for GitHub Pages sites. For more information, see GitHub Pages documentation.

Cloudflare DNS

The domain DNS for this website is managed through Cloudflare. Cloudflare may collect anonymous DNS traffic statistics as part of their service. MatData does not have access to individual DNS query data. For more information, see Cloudflare's Privacy Policy.

Content Delivery Networks (CDNs)

This website uses third-party CDNs to deliver resources efficiently:

  • Google Fonts: Fonts are loaded from Google's CDN, which may log requests and collect usage data.
  • jsDelivr: The YAML parsing library is loaded from jsDelivr CDN, which may log requests.

These CDN providers may collect data according to their own privacy policies. MatData does not control or have access to this data.

Your Data Rights

Since MatData does not directly collect or store personal data:

  • There is no personal data to access, correct, or delete from MatData servers.
  • For data collected by Google Analytics and other third-party services, please refer to their respective privacy policies and opt-out mechanisms.

Changes to This Privacy Statement

We may update this privacy statement from time to time. Any changes will be posted on this page with an updated "Last updated" date.

Contact

If you have any questions about this privacy statement, please contact us through the contact information on our website.
